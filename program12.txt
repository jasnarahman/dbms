PL/SQL PROGRAMS – TRIGGERS 
1. Create a trigger to handle inserts to the product relation ( if price < 5 the set price to 10).
mysql> delimiter //
mysql> create trigger trig_relation
    -> before insert
    -> on product2
    -> for each row
    -> begin
    -> if new.price<5
    -> then
    -> set new.price=10;
    -> end if;
    -> end;
    -> //
Query OK, 0 rows affected (0.02 sec)
